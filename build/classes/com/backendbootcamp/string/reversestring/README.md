# 1 - Reverse given string

## 🧩 Problem

Given a string, reverse the order of its characters and return the reversed string.

For example, if the given string is `"BackendBootcamp"`, the expected reversed string is `"pmactooBkcaDnekcaB"`.

The goal is to practice string manipulation and understand different ways of reversing a string in Java.

---

## 📥 Input

The input is a string containing characters that need to be reversed.

**Example:**

```text
BackendBootcamp
```

---

## 📤 Output

Return the input string with its characters arranged in reverse order.

**Example:**

```text
pmactooBkcaDnekcaB
```

---

## 💡 Examples

### Example 1

**Input**

```text
hello
```

**Output**

```text
olleh
```

### Example 2

**Input**

```text
Java
```

**Output**

```text
avaJ
```

### Example 3

**Input**

```text
BackendBootcamp
```

**Output**

```text
pmactooBkcaDnekcaB
```

---

## 🎯 Interview Focus

This problem is commonly used to test basic string manipulation skills in Java.

While solving it, you may explore multiple approaches, such as:

* Using a `for` loop
* Using `StringBuilder`
* Using the `reverse()` method
* Reversing the string without using `reverse()`
* Converting the string into a character array
* Understanding `String` immutability

The objective is not only to get the correct output but also to understand the **time and space complexity** of each approach.
